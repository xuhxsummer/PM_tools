# 水滴动画实现说明

当前入口动画依据参考视频逐帧拆成五个阶段，不能退化为一个圆形 `backdrop-filter` 放大镜。

## 阶段

1. **底部液膜（0%～36%）**
   - 水滴主体一开始已经很大，圆心位于屏幕底部之外。
   - 上拉时主要表现为解除屏幕底边裁切，不是小球等比放大。
   - 下半部显示局部蓝、青、紫色“微笑形”焦散光，不做整圈彩虹边框。

2. **脱离底边（36%～49%）**
   - 大液滴由底部附着状态收拢成完整球体。
   - 原始介绍文字淡出，焦散光快速减弱。

3. **液态传送窗口（49%～90%）**
   - 下一屏标题先出现在水滴内部，而不是先出现在背景后再被放大。
   - 中央相对可读，边缘通过 SVG 位移、青红错位和圆形裁切产生折射与色散。
   - 水滴边上升边收缩，内容逐渐被挤向边缘。

4. **内容交接（约 79%～97%）**
   - 水滴内部的折射标题逐渐消失。
   - 背景中的正常标题交叉淡入，避免出现两个完整标题。

5. **透明小水滴落定（90%～100%）**
   - 最终停在标题上方，只有透明边缘、高光与柔和底部阴影。
   - 使用轻微形变收束，不做明显弹跳。

## 交互

- 用户在页面下半部向上拖动，拖动只直接控制前半段，松手超过阈值后自动完成剩余动画。
- 横向手指位移仅少量影响水滴位置，制造液体跟手但滞后的感觉。
- 动画完成后才开放底部登录/直接使用按钮，防止过渡途中误触。
- 系统开启“减少动态效果”时，CSS 会关闭循环动画和长过渡。
