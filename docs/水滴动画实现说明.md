# 水滴动画实现说明

## 当前实现：V5 Liquid Glass

当前入口是 `LiquidGlassIntro.tsx`，动画层由两条渲染路径组成：

- `LiquidGlassRenderer.ts`：主路径，WebGL 1 + GLSL。
- `LiquidGlassCanvas2DRenderer.ts`：WebGL 不可用时的光学降级路径。
- `LiquidGlassRendererV4.ts`：本次重构前的完整 WebGL V4，保留回退。

V5 不依赖普通 `backdrop-filter` 作为核心效果。页面的旧画面和目标画面会先被捕获为两张纹理，再由液体 SDF mask、UV 位移、分离 RGB 采样和边缘光学合成完成折射。

### 统一 progress 状态

| progress | 可见状态 |
| --- | --- |
| 0～0.23 | 屏幕底部之外的大液面球冠被向上拉起 |
| 0.23～0.52 | 球冠收拢；底部 reservoir 通过短液颈与主体连接 |
| 0.475～0.565 | 短液颈逐步夹断，主体连续脱离 |
| 0.52～0.91 | 透明大球上升并缩成顶部核心 |
| 0.91～1 | 小玻璃核心稳定，开启气泡发射 |

反向拖动复用同一套几何状态，不切换到另一段独立动画。目标纹理具有方向滞回：反向时会一直保留到球体接近底部，确保标题和登录按钮仍能在球内被放大、弯曲，然后才恢复初始画面。

### 液态几何

- 主体、底部 reservoir 和短液颈分别使用 ellipse SDF、tapered segment SDF。
- 三个形状通过 smooth minimum 连续融合。
- 旧版长 capsule 连接方式已完整保留在 V4 文件；V5 的连接点压缩到两个曲面临近位置，避免出现长柄水滴。
- 横向手势只造成有阻尼的偏移；接近核心时偏移逐渐收束。

### 真实透镜与色散

- 液体中心放大系数在大球阶段约为 `1 / 0.625`，即约 1.6 倍。
- 越接近边缘，UV 弯折越强；中心保持相对清透。
- 红、绿、蓝通道使用不同采样偏移，色散由真实背景采样产生。
- 边缘彩色能量来自 RGB 样本差异，不再使用固定整圈彩虹描边。
- 底部蓝/青/紫焦散弧只在附着阶段出现，并随 progress、曲率脉冲和横向拖动变化。
- 目标纹理包含标题、说明及完整登录区，因此反向球体经过底部时仍能折射按钮。

### Z-depth 气泡

- 气泡使用对象池和 RAF 更新，不触发逐帧 React render。
- 每颗气泡保存 birth time、XYZ、XYZ 速度、尺寸、旋转、种子和透明度。
- 38% 为慢速远景层，最长约 11.5 秒；其余为快速前景层。
- 出生点集中在顶部玻璃核心附近，尺寸由 Z 深度主导。
- Z 越接近相机，透视尺寸越大，X/Y 发散也被透视同步放大。
- 不再使用 `GL_POINTS`，而是每颗气泡生成两个 GPU 三角形，规避移动 GPU 的最大点尺寸限制。
- 大泡主要依靠越过顶部/左右 viewport 被裁切，不在画面内部提前淡出。
- 反向拖动会停止继续发射，但已经生成的远近景气泡会继续自然离场。

### 性能与降级

- WebGL DPR 上限为 1.65；Canvas 2D DPR 上限为 1.5。
- 背景纹理只在初始化和 resize 后捕获。
- 粒子数据写入复用的 `Float32Array` 和动态 VBO。
- 系统开启“减少动态效果”时不发射粒子，并缩短自动归位时间。
- Canvas 2D 降级路径使用分条纹理拉伸模拟透镜，并保留同一套 progress、纹理滞回和双层 Z 粒子生命周期。

## 历史 V3 说明（保留用于对照）

V3 入口动画依据参考视频拆成五个阶段，但仍以 DOM/SVG/CSS 为核心。以下内容保留用于版本对照，当前入口不再使用该方案。

## 阶段

1. **底部液膜（0%～32%）**
   - 水滴主体一开始已经很大，圆心位于屏幕底部之外。
   - 上拉时主要表现为解除屏幕底边裁切，不是小球等比放大。
   - 下半部显示局部蓝、青、紫色“微笑形”焦散光，不做整圈彩虹边框。

2. **脱离底边（32%～50%）**
   - 大液滴由底部附着状态收拢成完整球体。
   - 原始介绍文字淡出，焦散光快速减弱。

3. **液态传送窗口（50%～90%）**
   - 下一屏标题先出现在水滴内部，而不是先出现在背景后再被放大。
   - 中央相对可读，边缘通过 SVG 位移、青红错位和圆形裁切产生折射与色散。
   - 水滴边上升边收缩，内容逐渐被挤向边缘。

4. **内容交接（约 79%～97%）**
   - 水滴内部的折射标题逐渐消失。
   - 背景中的正常标题交叉淡入，避免出现两个完整标题。

5. **透明小水滴落定（90%～100%）**
   - 最终停在标题上方，只有透明边缘、高光与柔和底部阴影。
   - 使用轻微形变收束，不做明显弹跳。

## 顶部泡泡纵深流

- 初始介绍页不显示彩色泡泡；水滴进入内容交接阶段后才挂载泡泡流，确保首次出现从远处的小点开始。
- 所有泡泡都从最终小水滴附近的同一透视消失点发射，不允许从屏幕顶部往下漂。
- 每个泡泡沿独立的向上、向两侧放射路径运动，使用“位移 + 大比例缩放 + 分层遮挡”表现从远处朝镜头冲来的纵深感。
- 泡泡在靠近屏幕边缘时达到最大尺寸并淡出；大泡泡离场的同时，新小泡泡从中心补上，形成连续流，而不是整团一起出现或一起重置。
- 24 个泡泡使用不同的尺寸、路径、速度、延迟、旋转角和层级，避免重复节奏明显。
- 系统开启“减少动态效果”时只保留少量静态泡泡，防止造成不适。

## 交互

- 用户在页面下半部向上拖动，拖动只直接控制前半段，松手超过阈值后自动完成剩余动画。
- 横向手指位移仅少量影响水滴位置，制造液体跟手但滞后的感觉。
- 动画完成后才开放底部登录/直接使用按钮，防止过渡途中误触。
- 系统开启“减少动态效果”时，CSS 会关闭循环动画和长过渡。
